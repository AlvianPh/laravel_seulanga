# UI/UX Pro Max - Design Intelligence

Panduan kecerdasan UI/UX profesional untuk web & mobile app. Gunakan skill ini saat mendesain halaman baru, merapikan/mempercantik komponen, memilih tipografi, warna, spacing, micro-interactions, serta meningkatkan kualitas estetika dan ergonomi antarmuka pengguna.

## When to Apply

Gunakan Skill ini saat tugas melibatkan **struktur UI, keputusan desain visual, pola interaksi, estetika modern, atau quality control pengalaman pengguna (UX)**:
- Mendesain atau mempercantik halaman (dashboard, form, table, profile, landing).
- Memilih/mengatur sistem warna, hierarki tipografi, padding/spacing, card elevation/shadow.
- Meningkatkan perceived quality: clean, modern, state of the art, tidak kaku/basic.
- Menjaga kontras WCAG, status visual yang jelas, dan navigasi responsif.

## 10 Prioritas Desain UI/UX Profesional

| Prioritas | Kategori | Fokus Utama | Anti-Pattern yang Harus Dihindari |
|---|---|---|---|
| 1 | **Accessibility (A11y)** | Kontras teks min 4.5:1, visible focus ring, semantic HTML, readable font size | Teks abu-abu di atas abu-abu gelap, link/tombol tanpa label jelas |
| 2 | **Touch & Interaction** | Target klik minimal 40-44px, spacing antar tombol, visual feedback saat klik/hover | Tombol terlalu kecil/mepet, tidak ada feedback saat ditekan |
| 3 | **Visual Hierarchy & Depth** | Judul tegas, subtitle jelas, soft shadow (`shadow-sm`/`shadow-md`), subtle border | Semua teks memiliki ketebalan/ukuran sama, card flat tanpa kontras |
| 4 | **Style & Cohesion** | Menggunakan satu visual language yang konsisten, SVG icons (Heroicons/Lucide) | Mencampur icon emoji dengan SVG, ukuran icon tidak seragam |
| 5 | **Layout & Spacing** | Grid konsisten, spacing bernapas (16px/24px/32px), no horizontal overflow | Elemen terlalu padat/menempel ke tepi, tabel berdesakan |
| 6 | **Typography & Colors** | Font modern (Inter/Plus Jakarta Sans), skala teks seimbang, token warna semantik | Menggunakan font generic, warna terlalu jenuh/kontras menyilaukan |
| 7 | **Micro-interactions** | Transisi halus (150-200ms ease), hover state lembut, active indicator | Transisi kasar/instan, animasi berlebihan yang memperlambat kerja |
| 8 | **Forms & Validation** | Label selalu terlihat, pesan error jelas di dekat input, helper text informatif | Placeholder digunakan sebagai pengganti label |
| 9 | **Dashboard & Data** | Metric card dengan visual ringkas, status badge modern (pill), tabel terstruktur rapi | Tabel membingungkan tanpa badge/aksi yang jelas |
| 10 | **Dark Mode Polish** | Dark mode kontras halus (bg slate-900 / gray-800), border subtle, teks terang nyaman | Pure black (#000) pekat tanpa pemisah card |
